# AgentSystems — Brand standard

## Identity

- Product name: **AgentSystems** (one word, capital A and S).
- Repository slug: `agentsystems`.
- Tagline: **Intelligence that compounds.**
- Description: An intelligent production system that executes work, evaluates outcomes, and improves through evidence and experience.
- Initial focus: audiovisual production, beginning with Tamil animated shorts. Not a generic MCP server or a collection of tools.

## Product vocabulary

Use concise, factual language. Say “Result stored” when integrity is confirmed; do not claim creative quality or successful playback without independent evidence. Avoid “owner” in user-facing copy unless discussing an actual ownership or permission concept.

Infrastructure identifiers, package IDs, signing identity, OAuth resource URLs and existing storage keys are compatibility contracts, not brand names. Do not rename these solely for presentation. Change them only with a tested migration.

No final logo, typography or color palette has been approved. Use a clear typographic wordmark and restrained neutral interface until a deliberate visual identity is approved.
