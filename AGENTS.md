# Engineering guidance

Read README.md, BRAND.md, docs/DEVELOPMENT.md and docs/ROADMAP.md. The system owns complexity; the human defines objectives, boundaries, resources, quality and authority.

Keep changes bounded and evidence-backed. Preserve authorization, compatibility, durable work results, idempotency and recovery. Separate execution confirmation, integrity, media validity and creative evaluation. Test local-first. Never commit private data, credentials, configured deployments or generated builds. Do not deploy or incur cost without authorization. Document limitations rather than inventing successful outcomes.
